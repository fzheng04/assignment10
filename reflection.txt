This module was an introduction to several concepts that I had little to no experience with before, like Pydantic validation and password hashing. Before this assignment, I had no idea what Pydantic was or how passwords were actually stored in real-world applications. I learned that applications should never store passwords in plain text but instead, they use hashing algorithms such as Argon2 to securely store passwords and verify them without needing to know the original password. I also learned how Pydantic validates user input before it reaches the database, helping prevent invalid data from being stored. Using separate schemas for creating and returning users also showed me how applications can avoid exposing sensitive information.

One of the biggest challenges I encountered was configuring the development environment and getting everything to work together after building on previous modules.  I also encountered Docker port conflicts when running PostgreSQL containers and permission issues with pytest coverage files. This occurs because of changes made to previous module meant new configurations had to be done. I resolved these problems by checking my environment, adjusting Docker Compose settings, and changing how I ran my tests.

Overall, this module helped me better understand how real applications securely manage user information and how automated testing and CI/CD contribute to reliable software development. It taught me another important element of web development that is the importance of correctly storing sensitive user information.
